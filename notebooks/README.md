# Interactive Notebooks & Experiments

This directory contains interactive walkthroughs, benchmarking notebooks, and exploratory data analysis for **OmniRAG**.

### Files:
- `omnirag_demo_walkthrough.py`: End-to-end Python script demonstrating each component:
  1. Semantic Chunking
  2. BM25 Sparse Indexing
  3. Dense Vector Similarity (Gemini Embeddings)
  4. Reciprocal Rank Fusion (RRF)
  5. Knowledge Graph Entity & Relation Extraction
  6. Grounded Synthesis with Citation Spans
  7. Faithfulness & Hallucination Auditing
- Can be run directly with:
  ```bash
  python notebooks/omnirag_demo_walkthrough.py
  ```
